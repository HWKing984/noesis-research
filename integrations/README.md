# integrations/ · 外部数据源连接器

- `knowledge-graph/` —— **已实现**。只读适配器，唯一文献数据出口。
- `openalex/` —— 论文发现、元数据、开放获取信息及筛选。
- `crossref/` —— DOI 查询与元数据校验。
- `semantic-scholar/` —— 引用、参考文献、相似论文补充。

## 身份匹配纪律（硬约束）

外部记录匹配优先级：**DOI → 精确 arXiv ID → 明确来源标识**。
仅靠标题相似度的匹配**一律留为「待确认候选」**，不得合并论文身份。外部补充元数据写入独立业务表，不回写 SciBERT 图谱。
