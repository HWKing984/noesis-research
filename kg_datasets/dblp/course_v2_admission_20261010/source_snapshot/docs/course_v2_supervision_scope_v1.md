# V2 关系作用域与评测协议 v1

唯一机器配置为 `resources/course_v2_supervision_protocol_v1.json`。本批固定定义与证据表示，不训练、不推理、不修改V1，不宣称AI复核是人工金标准。

## 统一负例定义

抽取对象是**整篇原始摘要中可归属到该方法的用途/评测关系**，不是论文全文的穷尽事实，也不是现实世界的普遍真理。

`USED_FOR` 仍接受明确支持的应用目标、组件操作、代理训练操作和背景方法用途。四种 `taskRole` 是审核分层，不是参考答案特征。不能先用宽口径接受正例，再用“不是直接执行者”的窄口径造负例。

`NO_RELATION` 需要原文明确否定，或明确排他/不适用约束，且否定范围覆盖同一正关系定义。它否定的是本摘要所述的相应归属；不外推到方法在所有情境下的能力。

| 证据情况 | 处理 |
|---|---|
| 明确谓词及主体用途/评测归属 | 相应正例；保留角色、证据、来源 |
| 原文明示该主体不执行/不适用于相应任务，或明确排他且作用域一致 | 负例候选，仍需源文复核 |
| 方法分工不同，但没有排除间接支持 | `UNRESOLVED` |
| 数据集用于训练，没有说明是否也用于评测 | `UNRESOLVED`，不能自动标负 |
| 无谓词、共现、效果差或正文未出现某端点 | `UNRESOLVED`；诊断可记`NOT_EXPRESSED`，不作训练负例 |

现有5条反例全部撤回为未决：RL的表示使用与压缩操作分工3条、DDCSR组件交叉任务2条。原标签、原因和证据在父包与新账本中均保留。此举统一口径，**不会增加可用负例**。

## 双层共指证据

对本轮指定的3个提及对保留原先句/子句为 `anaphorContextSpan`、`antecedentContextSpan`，新增：

- `triggerSpan`：实际回指词的最小原文跨度。
- `resolvedEntityId` / `resolvedEntitySpan`：原文中的目标提及，不补正文没有的名字。
- `referentAliasIds`：仅显式同一名称的局部别名，例如SQuAD全名/缩写。
- `evidenceLevel`：`direct` 为句内明确语法归属，`alias` 为显式别名，`discourse_inferred` 为跨句/语篇解释。
- `coreferenceFactId` / `relationEvidenceLevel`：SQuAD两个别名共享一条事实链；三对评测关系整体均为语篇推断。

“which”对模型的句内归属不使“模型在哪个数据集上评测”自动变成直接证据。HumanEval句中的 `this method`、`our problems`分别指向策略和基准。原文跨度匹配仍不证明指代解释绝对正确。本批不宣称其余跨句/别名关系全部完成精细共指。

## 评测冻结及限制

论文组为拆分单元；同论文的arXiv版本、别名、提及对和文本窗口不跨训练/验证/测试。现有12篇锁为train-only。历史20,000篇语料身份、既有摘要选取身份和补充开发身份不进入新的验证/测试。

本批只生成元数据排除清单与12篇训练身份锁，**新验证/测试成员仍为空**。冻结协议不等于已经建好独立评测集，不能将旧测试成绩变成新模型成绩。

将来必须在读取新评测原文、标注和查看预测前，先固定新论文总体、抽样种子、样本量和元数据清单。代表性验证/测试在论文组层面均匀无放回抽样；长尾挑战集单独构建、单独报告，不混入总体指标。

模型输入保持原摘要与实体标记，不注入审核角色/共指真值。训练时同一论文/支持组每轮选一个提及对并按预定种子轮转别名，避免把20条同证据DDCSR提及当20个独立来源；本批没有执行采样或训练。

同时报告严格NER、严格端到端三元组P/R/F1、TP/FP/FN、无正例论文、逐类/角色来源论文数与覆盖率。参考实体RE仅为次要条件指标。支持组命中率描述每个支持组是否有正确提及，不等同独立事实准确率；无法归组的误报另报，不能靠合并误报制造高分。

未决对必须排除训练。评测参考不完整时不能把全部非已知正例预测当确定误报，也不能忽略未知预测后宣称完整Precision；完整pipeline成绩需完整裁决，或明确不确定/不可评分的分母与覆盖范围。

未来候选选择仅用固定的新验证集。实用门槛为端到端F1提高至少2个百分点，且同口径逐类TP、负例FP不退化；少于10篇参考来源的类别不足以作可靠泛化声明。不是统计显著性承诺，也不授权自动晋级。最终测试盲测一次；看测试再改模型后，该结果降为开发证据。

训练仍须另外冻结含可靠负例的训练快照、新验证身份与完整评测支持，并得到独立的执行契约。当前所有授权标志为false。
