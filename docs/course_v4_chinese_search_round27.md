# 轮次27：中文术语检索与双语展示

## 结果与使用方法

本机应用：http://127.0.0.1:8765/。刷新页面，在“方法候选”输入“扩散模型”；在“题名关键词”输入“知识图谱”或“大语言模型”；在“任务候选”输入“机器翻译”；在“会议或期刊”输入“AAAI会议”。各字段之间仍为AND条件，不是整句自然语言问答。展开“支持的中文术语与节点/关系说明”可查看全部22项固定词表和中文说明。

可复现单篇示例：题名关键词 `Denoising Monte Carlo Renders`，方法候选 `扩散模型`，其他条件留空。真实Neo4j返回 `conf/3dim/VavilalaVF25`；点击详情，显示“方法（METHOD）·扩散模型（Diffusion Models）”及“用于（候选）（USED_FOR）”。

## 课程报告中的应用意义与流程

面向中文使用者，用中文术语发现英文AI文献，再查看作者、会议/期刊、模型候选方法/任务和原题证据。中文入口减少术语语言障碍，不改变论文原始内容，也不代替阅读原文、核验候选关系和确定正式参考文献。

完整流程：

1. 校验输入字段、长度和分页；未知/重复参数拒绝。
2. 保留输入关键词，只在允许字段按完整术语命中固定词表 `zh_alias_v1`。保留原始中文匹配项并加入英文表达，单个字段内为OR。
3. 使用参数化Cypher查询当前课程graphId的真实Neo4j数据，不插值拼接用户输入，不使用离线结果兜底。
4. 返回原始书目，并在元数据记录实际展开词和词表版本。
5. 在页面显示中文类别、关系说明、已知术语别名，同时保留英文原题、作者姓名、原始实体文本、Unicode位置及模型来源哈希。
6. 未知中文原样查询；未命中只表示当前检索条件无匹配，不表示全领域没有文献。

领域和抽取模型不变。不是“用词典替代深度学习实体/关系抽取”：词表仅为应用检索入口，模型候选实体与断言仍来自原先冻结的NER→RE。

## 未改变的部分与限制

- 当前健康检查仍为20,000篇书目、19,999篇模型输出、1篇拒绝、21,497条候选断言。没有本轮重新导入、数据库写入、重新训练或重复最终测试。
- 仅应用展示中文说明，Neo4j Browser内的标签、关系类型与节点原始属性仍是英文；未更改数据库标识。USED_FOR/EVALUATED_ON是Assertion的predicate属性，不是新增直接边。
- 未翻译全部论文题名，未猜测作者中文姓名，未支持中文论文NER/RE；没有自动翻译服务、向量检索或整句意图解析。
- 词表完整术语精确触发，局部词、混合短语和未列同义词不会自动展开。底层仍为子串检索，不是语义等价判断；缩略词、连字符和未覆盖表达可能漏检。
- 中文说明不修复原有模型误报、实体漏报、姓名未消歧与概念别名未合并问题；候选断言分数未校准，仍无CITES引用网络。
- 不改变训练/标签快照、冻结权重、旧图谱包和旧测试成绩。按MLE工作流仅验证服务一致性与来源完整性，不能将中文入口上线称为模型质量晋级。
