# 摘要模型与NER→RE误差传播实验路线

第37轮按原train锁补采24篇、21篇匹配自复核/19篇BIO通过，真实NER48篇/6轮144步，固定dev与旧RE不变。NER总F1基本不变，pipeline F1 30.00%→26.49%，新增候选拒绝替换；[数据量单因素结果](system_status_round37.md)。漏实体减少但边界错误增多，不支持仅靠扩量足以解决，下一步训练侧逐次出现的上下文/角色和任务边界；不改dev参考或超参数追分，不消费test。以下路线和36及更早段落保留作历史设计记录。

2026-10-08技术评审后的实施路线，原设计如下保留，不是论文创新声明。35轮NER已训练；36轮以新的 `course_abstract_relation_v1.json` 部分标注合同完成明确关系修订、RE6轮/294步与5篇完整dev上的四种NER×RE对照。[开发和拒绝记录](system_status_round36.md)：新RE宏F1退化，NER组合召回与完整覆盖不满足护栏，不升级。部分实体对模块成绩不和完整文档pipeline混合；35轮合同/输入/成绩原样保留。下面“下一步”条目属于制定路线时的状态；当前下一步改为训练摘要/任务跨度/角色多样性和完整dev证据，不盲调RE或重跑test。报告暂停，不扩大2万篇书目或添加Agent框架。

## 迭代合同

目标：提高有证据的候选文献检索质量，重点降低错误的方法—数据集关系，同时保留召回率与弃权覆盖。用户决策仍是查看原文后选择候选文献，不自动决定“必须引用”。主指标是同一摘要dev队列上的严格pipeline Precision与F1；护栏包括Recall、DATASET/EVALUATED_ON逐类support、文档/实体对覆盖率、拒绝与未决比例、推理时间和显存。

不可接受：把UNRESOLVED当负例、把训练数据集视为评测数据集、静默截断、混入旧test、将AI同意写成真人gold、用softmax宣称事实概率。允许带原因弃权；弃权不能通过缩小评估队列隐藏。线上保留31轮图和旧模型，失败时不晋级。

## P0：先修正事实与口径

默认运行版本由 `resources/course_graph_runtime.json` 固定路径、graphId、manifest哈希；历史包显式选择，导出必须指定新目录。README同步33轮摘要标注与已完成的29轮留出评测；独立披露P/R/F1/support/coverage，历史执行源码与图谱清单不覆盖。

第09/17/29轮成绩均是已暴露的AI参考标签一致性。本轮只读这些封存指标说明局限；不重复运行它们，也不从这些测试错误挑选下一轮提示、词典、样本或阈值。后续错误发现与模型选择只在新train/dev进行。RE模块99.25%与pipeline60.07%的差不能简单相减成“NER造成的百分比”，需要同一输入/实体范围的对照。

## P1：标注质量与独立训练契约

当前37篇整篇train已逐篇AI判断/自复核，29篇NER候选、35个DATASET提及、8篇隔离；17条正关系候选和1,119个未决对。19篇dev待单独标注，19篇test内容保留。8段历史试标是这批训练文献的摘录，不作为独立样本重复计入或放入dev/test。

1. 冻结可执行的 `abstract_v1` 契约后，单独对dev盲于模型预测标注/复核；不依dev题名补训练词表，不通过只保留容易文档调高覆盖条件下的分数。标注提示/跨度规则若后续修改，保留旧标签并重审受影响train/dev，不触碰test。
2. 检查8篇隔离：区分共享中心词并列、普通词多义、源文本黏连、宽泛类别边界、非研究内容。能由明确原文规则解决才生成新修订收据；不为凑数解除隔离或重写原文。
3. 优先在训练侧补DATASET/EVALUATED_ON和明确负例。负例必须是范围内特定头尾实体对的明确判断及证据/原因；“同文出现”“只提到训练”“没有看到评测”本身既不证明正关系，也不必然证明负关系。无法确定继续UNRESOLVED。增加训练文献或明确负例时先锁来源论文组，不能由已暴露test中的失败样本反向挑选。
4. 新契约允许在**实体标注完整且复核通过**的训练文档中逐对使用明确正/负关系，屏蔽未决对。必须另行实现和验证这一规则，不能修改旧 `eligible_tasks` 或旧封存RE输入来偷偷放行17条候选。记录入选文档、实体对分母、按类别排除数；避免把未知对训练成负例。当前17条文件仍是候选，不自动成为新训练集。
5. 严格pipeline主评估仅使用完整实体与完整关系标注的可判定dev/test文档，包括零正关系文档，报告原锁定队列覆盖率。部分标注文档单独报告，不和主分数混合；不能把未知关系当FP/TN。全队列还应披露无法判定和系统拒绝情况。

训练合同最低字段：`sampleId / publicationId / groupId / split / textKind=abstract / text / textSha256 / sourceManifestSha256 / receiptSha256 / labelSource=ai_pseudo`；实体为原文Unicode连续跨度，关系含类型、证据、状态。使用原32轮论文组划分，复用其独立来源合同并绑定版本；保持题名模型合同原样。最大512token，超长隔离，不截断。推理使用相同文本单位与预处理。首版只做摘要，不把标题直接拼进去；以后确需“标题+摘要”时另记分隔符、两段位置映射与对应标注，不能称为当前已实现能力。

独立人工抽检仅为可选研究扩展，不要求用户标注，不作为当前AI路线推进的前置条件；没有独立来源就明确没有。换提示的同会话自复核仍不算独立评估。独立AI交叉标注若实施，也需记录实际模型来源与盲审过程，不能伪造来源或称为human gold。

## P2：误差传播实验，先dev再锁test

复用 `train_course_ner.py` 的严格BIO对齐/解码和评分、`train_course_relation.py` 的实体标记/逐类指标/既有平衡损失，以及 `evaluate_course_relation.py` 的候选对与严格pipeline匹配规则。为摘要加独立入口与合同，不改旧final-test入口或全局题名配置。先做离线预检和小规模真实训练；首轮保留词典NER和实体类型多数RE作为基线，未决不由基线填负例。

在同一可判定摘要dev子集上做以下交叉对照，文本、标签、候选生成规则、分母和评分固定：

| 对照 | NER | RE | 用途 |
|---|---|---|---|
| A | 冻结旧权重 | 冻结旧权重 | 摘要上的迁移基线，不冒称线上题名性能 |
| B | 新摘要NER | 冻结旧权重 | 隔离实体模型变化 |
| C | 冻结旧权重 | 新摘要RE | 隔离关系模型变化 |
| D | 新摘要NER | 新摘要RE | 测整体和交互影响 |

每种RE另用相同AI参考实体评分，作为诊断oracle，不送入真实pipeline冒充预测实体。保存每个文档的预测跨度、实体对、证据、版本和拒绝原因。

dev错误分解：对每条参考正关系检查头/尾实体是否出现、边界/类型是否正确、合法实体对是否生成、RE是否错判或弃权；上游多种错误同时存在时保留全部标记，并使用固定的“实体缺失→类型→边界→候选生成→RE判定”优先级给出一个主因，不能把重叠计数相加成总错误数。预测正关系则分别记录错误端点、正确端点上的错关系、未知标签/源标注歧义。数据/标注/契约故障单列，不能全算模型错误。

根据dev主因一次改一个因素：若稀有实体漏识别优先补训练支持或比较既有加权损失；若边界错误优先修训练标签和共享对齐；若端点正确仍错关系，再比较局部证据输入。合法BIO约束曾在31轮dev退化，不能不经新dev比较直接启用。首轮不换联合抽取、大模型或新框架。阈值仅由dev选择；未校准分数始终保留原语义。对置信度校准如支持不足，标“未校准”，不为显示百分比硬拟合。

每次输出P/R/F1、TP/FP/FN、逐类support、文档/实体对coverage及排除原因；主指标和护栏都要与A及简单基线比较。训练后先锁checkpoint、超参数、阈值、源码/输入哈希、评估规则与晋级门槛，然后才对保留19篇test标注并一次性评分。真实标注/测试支持不足时可以给探索性成绩，但不能宣布稀有类已解决或重复按该test调参。

晋级至少要求同队列pipeline Precision与F1不退化、Recall无已声明的不可接受退化、稀有类别不靠零support蒙混、覆盖变化透明、工程检查/同文证据核验通过。类别最低支持量和允许退化幅度须在训练前由独立合同明确；不是看到结果后设门槛。19篇保留test可能仍不足，不能为通过门槛事后筛选这19篇；若需要更大测试队列，应在选择模型前另锁未暴露文献，旧19篇仍保留其原角色。

## P3：知识质量验收后再扩应用

先保持候选断言、原文证据、模型版本、消歧状态与可退回旧图。语义检索、方法—任务证据对比、有引用约束Agent都在质量验收之后实施；DBLP仍无真实引用网，不能生成伪CITES或可靠被引次数。P2失败时不为演示效果升级图谱事实等级。
