# 第51轮：质量补强迭代约定

用户重新授权继续解决模型可靠性、概念归一和作者消歧。本轮不是第50轮工程验收的重写，也不编写完整课程报告。

## 固定基线与范围

- 在线图谱保持第31轮；历史作者恢复、图谱、模型、标注、测试与第50轮证据不修改。
- 作者：检查全部9,064个未决署名；仅凭有效ORCID、唯一非消歧DBLP主页和姓名兼容证据恢复身份。校验码只证明标识格式，不证明真实身份。没有充分证据的署名继续独立隔离，不按同名/合作者猜测合并。
- 概念：分类型的显式同义词表；缩写须明确约定，数字版本、变体及子任务不抹掉。保留原文提及、断言、身份映射和合并清单。归一不纠正抽取类别，不把候选断言变成事实。
- 模型：先复用已训练模型与训练侧错误分析，实施一个固定、可回放的证据约束实验。训练/开发侧单独记录；不接触保留测试正文，不遍历阈值，不把弃权改为NO_RELATION。

## 假设与验收

1. 未决署名中的ORCID可提供新增权威匹配。必须记录新增、冲突、无主页和仍未决数量，所有88,762条署名保持可追溯。
2. 高频概念的受控同义词可以减少重复并改善检索。必须记录每个旧概念的去向；BERT/RoBERTa、YOLO版本、DATASET版本等不得被宽泛合并。
3. 关系模型跨整篇摘要的实体对笛卡尔积容易输出无局部证据关系。独立固定证据约束只输出有原文局部支持的候选，其余明确弃权；报告精确率、召回率、F1及输出/证据覆盖率，不能用弃权隐藏假阴性。

失败条件：来源哈希改变、错合并、丢失原文提及/署名/断言、越界读取测试、降低升级门槛或将软最大置信度宣传成正确率。所有产物新目录；候选不过原门槛不替换线上模型/图谱。

范围触达：新增质量处理脚本、受控词表、单元测试、新输出清单和状态文档。复用原有JSONL、哈希、图谱验证、模型推理和评估工具；不新增依赖、不修改冻结模块、不搭建新框架。
