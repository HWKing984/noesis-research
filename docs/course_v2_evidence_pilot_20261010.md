# V2 第一批：证据数据准备

2026-10-10。V2已开始实施，但本批是数据准备，不是新模型训练或准确率提升。按MLE工作流先锁任务、来源、隔离与停止条件；V1继续作为课程交付版本，图谱、权重与应用配置未修改。

## 已完成的范围

- 固定[任务与标注契约](../resources/course_v2_evidence_pilot_v1.json)：题名与整篇摘要分开，不将摘要事实写进题名标签；实体保留原文Unicode偏移；方法、任务、数据集不按共现强行配关系。
- 复用65篇可用摘要的70篇训练来源队列，保持5篇NER隔离；校验原文哈希、AI收据、源文件manifest及训练身份。
- 按源文件顺序选取12篇不同论文：4篇旧评测正例、4篇旧明确负例、4篇含数据集与未决对的论文。使用旧训练标签定向选样，不根据开发/测试错误或模型新预测选样；不代表总体分布。
- 首批原文、源URL、旧实体和关系、证据片段、未决项与上游收据哈希已生成[逐篇复核档案](../kg_datasets/dblp/course_v2_evidence_pilot_20261010/review_dossiers.jsonl)。复核状态明确为pending，不冒充本批新标注或新验证的事实。
- 读取白名单只包括6份TRAIN/身份元数据JSONL，不解析任何dev/test正文；预留摘要test仅二进制SHA核对。文献ID、论文组和arXiv身份与既有留出元数据无冲突；未检查预留test正文近重复，不宣称所有形式泄漏已排除。
- 原生产两套权重、运行配置、应用源码、页面及58版图manifest六个保护文件前后SHA相同；没有训练、推理、采集新论文、入库、替换模型或重启服务。

## 复核规则及下一批

先按12篇完整原文复核边界、类别和归属，再逐对处理关系：

1. 任务必须是原文明确的研究任务，不能把数据模态/研究对象自动当成TASK。
2. 数据集名称不等于评测证据；方法、组件、被压缩模型及评价执行者的角色分别核对。
3. USED_FOR/EVALUATED_ON需要对应头尾提及的原文证据，组件不自动继承“本文模型”的结果。
4. 负例必须有明确角色或数据集用途对比；训练提及、表现差、共现、未表达均不能单独判NO_RELATION。
5. 不能确定则保留UNRESOLVED；同义词合并不能改变字面证据、偏移或模型版本。
6. 所有修正写入独立V2收据/更改账本，不回填或覆盖旧训练数据；AI初标与同会话复核仍非独立人工gold。

本批停止条件已经达到：契约、12篇源绑定档案、类别库存和隔离检查落地。下一批的有限任务是完成这12篇语义复核并统计可用/退回/未决项，不直接新增训练轮次。

后续训练还有两个前置缺口：通过校验的V2复核标签，以及单独锁定的训练/验证/最终测试与检查点选型方案。旧暴露开发集不能当新盲测；代表性随机评测与定向稀有挑战集分开报告。没有在本批重新划分或读取预留最终测试数据。
